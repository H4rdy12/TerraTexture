TerraTexture

DEM curvature analysis + soft-light / luminosity-blended shaded relief visualization.

Core pieces (no rasterio/contextily required): - derivatives.curvatures / hillshade -- Zevenbergen & Thorne (1987) - blend.soft_light / luminosity_blend -- Photoshop/SVG blend modes - stretch.normalize / stretch_std -- percentile / std-dev stretches - plotting.plot_dem_curvature_softlight -- 6-panel summary figure

Raster I/O (requires rasterio): - io.load_dem / load_dem_mosaic / _open_raster

Remote/open-data DEM sources (requires rasterio + requests; basemap draping additionally requires contextily): - sources.stac_search / arcticdem_mosaic / rema_mosaic -- dynamic STAC APIs (PGC) - sources.list_stac_collections / stac_collection_items / opentopography_mosaic -- static/search-less STAC catalogs (OpenTopography, and any other STAC catalog by URL) - sources.make_demo_geotiff - basemap.plot_dem_basemap_luminosity_relief / add_relief_basemap - overlay.burn_data_onto_relief

Each of these groups is importable independently -- e.g. you can use TerraTexture.derivatives and TerraTexture.blend with only numpy/scipy installed, with no rasterio or contextily on the system at all.

def curvatures(dem, cellsize): 
41def curvatures(dem, cellsize):
42    """Return (profile_curvature, planform_curvature) arrays, same shape as
43    dem. NaN cells in `dem` (nodata/voids) are nearest-filled for the
44    calculation and set back to NaN in the output."""
45    dem_filled, nan_mask = _fill_nan_nearest(np.asarray(dem, dtype=np.float32))
46
47    p, q, r, t, s = _derivatives(dem_filled, cellsize)
48    p2q2 = p ** 2 + q ** 2
49
50    with np.errstate(divide="ignore", invalid="ignore"):
51        profile = -(r * p ** 2 + 2 * s * p * q + t * q ** 2) / (p2q2 * (1 + p2q2) ** 1.5)
52        planform = -(r * q ** 2 - 2 * s * p * q + t * p ** 2) / (p2q2 ** 1.5)
53
54    # flat cells (p2q2 ~ 0) -> undefined -> set to 0
55    flat = p2q2 < 1e-9
56    profile = np.where(flat, 0.0, np.nan_to_num(profile, nan=0.0, posinf=0.0, neginf=0.0))
57    planform = np.where(flat, 0.0, np.nan_to_num(planform, nan=0.0, posinf=0.0, neginf=0.0))
58
59    profile = np.where(nan_mask, np.nan, profile)
60    planform = np.where(nan_mask, np.nan, planform)
61    return profile, planform

def luminosity_blend(backdrop_rgb, luminosity): 
104def luminosity_blend(backdrop_rgb, luminosity):
105    """SVG/Photoshop 'Luminosity' blend mode: SetLum(backdrop, Lum(source)).
106    Keeps backdrop_rgb's hue AND saturation intact, replacing only its
107    lightness with `luminosity` (H, W) array in [0, 1]. This is the
108    correct operation for draping a greyscale relief over colour imagery
109    -- unlike per-channel soft-light, it can't desaturate or shift hue.
110
111    Dispatches to the Rust kernel (see module docstring) when available
112    and the inputs are plain float32 arrays of the expected shape --
113    (H, W, 3) for backdrop_rgb, (H, W) for luminosity; otherwise uses
114    the pure-numpy implementation below. Same result either way.
115    """
116    if _is_fast_path_luminosity_blend(backdrop_rgb, luminosity):
117        return _rust.luminosity_blend(
118            np.ascontiguousarray(backdrop_rgb), np.ascontiguousarray(luminosity),
119        )
120    return _luminosity_blend_numpy(backdrop_rgb, luminosity)

def normalize(arr, low=1, high=99): 
14def normalize(arr, low=1, high=99):
15    """Percentile-stretch an array to [0, 1] (robust to outliers). NaNs
16    (nodata) are ignored for the percentile calc and pass through as NaN.
17
18    Preserves `arr`'s own dtype: `np.nanpercentile` always computes
19    internally in float64 and returns float64 scalars regardless of
20    input dtype, which would otherwise silently upcast a float32 input
21    to float64 in the subtraction below (unlike a plain Python float,
22    a numpy float64 scalar is NOT exempt from promotion under NEP 50)."""
23    arr = np.asarray(arr)
24    lo, hi = np.nanpercentile(arr, [low, high]).astype(arr.dtype)
25    return np.clip((arr - lo) / (hi - lo + 1e-12), 0, 1)

def stretch_std(arr, n_std=4): 
28def stretch_std(arr, n_std=4):
29    """Mean +/- n_std*std stretch to [0, 1] -- the "stretched N standard
30    deviations" symbology used for curvature/hillshade in ArcGIS Pro.
31    NaNs are ignored for the stats and pass through as NaN."""
32    mean = np.nanmean(arr)
33    std = np.nanstd(arr)
34    lo, hi = mean - n_std * std, mean + n_std * std
35    return np.clip((arr - lo) / (hi - lo + 1e-12), 0, 1)
